# حالة التنفيذ

## منجز في الحزمة الحالية
- بنية Next.js + TypeScript.
- PostgreSQL + Prisma schema.
- واجهة RTL ولوحة تحكم وصفحات المنتجات والطلبات والعملاء والمخزون والمحاسبة.
- API لإنشاء المنتجات والطلبات وتغيير الحالة.
- snapshots للمنتجات داخل الطلبات.
- سجل حالات وتدقيق للأحداث الأساسية.
- استحقاق عمولة idempotent عبر قيد فريد عند التسليم إذا وُجد إعداد عمولة.
- اختبارات منطقية صغيرة.

## قيود حرجة
- لا توجد مصادقة فعلية أو صلاحيات؛ جميع APIs الحالية غير محمية.
- لا يوجد خصم أو حجز مخزون عند إنشاء الطلب؛ صفحة المخزون تحذّر من ذلك.
- FIFO موجود كدالة منطقية فقط، وليس مربوطًا بعد بدورة الطلب.
- لا توجد قيود محاسبية تلقائية ولا تسويات شحن أو مشتريات أو مرتجعات.
- لا توجد migrations مولدة داخل الحزمة؛ يجب إنشاؤها بأمر Prisma محليًا.
- لم تُشغّل الحزمة في بيئة Node ولا تم التحقق من البناء في هذه الجلسة.

**لا تنشر التطبيق على الإنترنت ولا تستخدم بيانات حقيقية قبل إغلاق القيود الحرجة.**
