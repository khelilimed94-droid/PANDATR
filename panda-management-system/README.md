# Panda Management System

نظام عربي لإدارة عمليات التجارة الإلكترونية. هذه النسخة هي **مرحلة تأسيسية قابلة للتشغيل** وليست نظام ERP مكتملًا أو جاهزًا للاستخدام المالي الفعلي.

## ما يعمل في هذه النسخة

- واجهة عربية RTL متجاوبة.
- PostgreSQL مع Prisma ORM.
- إنشاء المنتجات مع التحقق من SKU الفريد.
- إنشاء الطلبات مع بيانات العميل والمنتجات ولقطات اسم المنتج وSKU والسعر.
- صفحة تفاصيل الطلب وسجل تغيّر الحالة.
- قواعد انتقال أساسية لحالات الطلب.
- إنشاء استحقاق عمولة مرة واحدة عند التسليم **إذا كان للبائع إعداد عمولة محفوظ**.
- صفحات أولية للمخزون والعملاء ودليل الحسابات.
- سجل تدقيق للأحداث الأساسية.
- اختبارات لوظائف FIFO وانتقالات الحالات وتوازن القيود.

## وظائف لم تكتمل — لا تعتبرها متاحة

- تسجيل الدخول والجلسات والصلاحيات الفعلية على الخادم وRLS.
- حجز المخزون وخصمه تلقائيًا من دفعات FIFO عند إنشاء الطلب أو تسليمه.
- إدارة المشتريات والمدفوعات وديون الموردين.
- تسويات شركات الشحن والتحويلات الجزئية.
- المرتجعات والتسويات المالية.
- إنشاء وترحيل القيود المحاسبية تلقائيًا.
- دفع العمولات على دفعات وسياسة عكسها بعد المرتجع.
- استيراد XLSX/CSV، التصدير، المرفقات، النسخ الاحتياطي الآلي.
- اختبارات تكامل وقبول شاملة.

لا تُدخل بيانات العملاء الحقيقية ولا تعتمد أرقام الربح أو المخزون من هذه النسخة قبل استكمال هذه الوظائف واختبارها.

## المتطلبات

- Node.js 22 أو أحدث
- Docker Desktop مع Docker Compose
- npm

## التشغيل المحلي باستخدام Docker

1. انسخ الملف البيئي:

   ```bash
   cp .env.example .env
   ```

2. شغّل قاعدة البيانات فقط:

   ```bash
   docker compose up -d db
   ```

3. ثبّت الحزم وأنشئ عميل Prisma:

   ```bash
   npm install
   npx prisma generate
   ```

4. أنشئ الجداول في قاعدة البيانات:

   ```bash
   npx prisma migrate dev --name init
   ```

5. أضف بيانات تجريبية وهمية:

   ```bash
   npm run db:seed
   ```

6. شغّل التطبيق:

   ```bash
   npm run dev
   ```

ثم افتح http://localhost:3000

> بيانات المدير التجريبية التي يضيفها seed ليست تسجيل دخول فعليًا في هذه النسخة. لا يوجد نظام مصادقة جاهز بعد.

## تشغيل التطبيق وقاعدة البيانات داخل Docker

يُستخدم هذا المسار بعد إنشاء ملف migration أولًا محليًا وإيداعه في Git:

```bash
docker compose up --build
```

## قاعدة البيانات

يحتوي `prisma/schema.prisma` على مخطط البيانات الأولي. لإنشاء migration أول مرة:

```bash
npx prisma migrate dev --name init
```

احتفظ بمجلد `prisma/migrations` الناتج في Git؛ لا تعتمد على `db push` في الإنتاج.

## متغيرات البيئة

- `DATABASE_URL`: عنوان PostgreSQL.
- `SESSION_SECRET`: محجوز لإضافة المصادقة لاحقًا، ولا يُستخدم بعد في هذه النسخة.

لا ترفع `.env` إلى GitHub. غيّر كلمات مرور Docker المحلية والأسرار قبل أي نشر.

## GitHub

بعد مراجعة الملفات وإنشاء migration وتشغيل الاختبارات:

```bash
git init
git add .
git commit -m "Initial Panda Management System foundation"
git branch -M main
git remote add origin https://github.com/USERNAME/panda-management-system.git
git push -u origin main
```

أنشئ المستودع في GitHub بنفسك أو فوّض صلاحية مناسبة قبل تنفيذ أوامر الرفع. لم يتم رفع أي شيء إلى GitHub من هذه الحزمة.
